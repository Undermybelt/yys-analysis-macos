# 平安志 macOS 版

来源：<https://gitee.com/tigerdonotcry/yys-analysis>

本仓库是平安志的 macOS 移植。原项目面向 Windows，用桌面版缓存目录或进程内存读取阴阳师御魂。macOS 上的 `/Applications/阴阳师.app` 是 iPhone 客户端封装，没有那份缓存，也不能沿用 Windows 的进程注入，所以这一版去掉了桌面版读取、内存读取、MuMu 模拟器读取和桌面版多开。

保留的部分：

- 御魂分析、模拟强化、神奇海螺、式神录、角色档案和评分规则；
- 藏宝阁公开商品链接导入。

数据来源只剩藏宝阁。打开 **数据读取 → 藏宝阁导入**，粘贴公开商品详情页链接，预检后确认导入。

## 构建

需要 Node.js 22、Rust stable 和 Xcode 命令行工具。

```bash
npm install
npm run build
npx tauri build --bundles app
```

产物在 `target/release/bundle/macos/平安志.app`。

# 平安志

平安志是一款面向《阴阳师》的 Windows 桌面工具，用来读取自己的御魂和式神数据，分析御魂价值，模拟强化，并根据目标面板给出配装与强化建议。

## 第一次使用

打开软件后，先从左侧 **数据读取** 选择一种数据来源：

### 方式一：桌面版读取

1. 使用**新版阴阳师桌面版**，不要使用旧版客户端。
2. **先登录游戏**，让桌面版生成当前账号的本地缓存；未登录时通常找不到可读取的御魂存档。
3. 在平安志中打开 **数据读取 → 桌面版**。
4. 选择游戏目录，扫描并选择需要读取的账号。
5. 核对本次读取的御魂、式神数量，确认后导入。

桌面版读取为本地只读读取，不会在游戏中自动强化、锁定或清理御魂。找不到账号或库存时，请先回到新版桌面版登录游戏，再重新扫描。

### 方式二：藏宝阁导入

1. 在藏宝阁找到要读取的公开商品。
2. 复制商品详情页链接。
3. 在平安志中打开 **数据读取 → 藏宝阁导入**，粘贴链接并点击预检。
4. 核对公开商品中的御魂和式神数量，确认后导入。

藏宝阁只读取公开商品信息。导入后，御魂会进入 **御魂分析**，公开的式神会进入 **式神录**；装备关系、货币和商品价格不会写入本地数据。

> 每次确认导入都会替换当前本地数据。导入失败时不会替换旧数据；如果想保留旧库存，请在导入前自行备份来源数据。

## 导入后怎么玩

### 1. 御魂分析：查看、分析和打分

进入 **御魂分析**，可以：

- 按套装、号位、星级、等级、主属性和副属性筛选御魂；
- 查看单枚御魂的完整属性、强化次数、评分规则和评分解释；
- 按当前启用的评分标准批量计算御魂分数；
- 查看值得强化、等待复评、建议停止、可清理和用途冲突等结果；
- 进入 **一速御魂**，计算当前库存中的一速排行和候选组合；
- 进入 **PVE 面板**，查看当前库存能够组成的 PVE 输出方案；
- 使用御魂雷达，对不同套装和属性进行库存对比。

评分是同一套标准内的比较工具，不是脱离用途的绝对价值。建议先配置自己的评分标准，再根据自己的 PVE/PVP 需求判断是否保留或强化。

### 2. 御魂评分标准：配置、创建和分享规则

进入 **御魂评分标准**，可以新建或复制一份标准，配置：

- 适用场景：全部、PVE 或 PVP；
- 套装、号位和主属性；
- 必备副属性、核心属性和普通属性；
- 保留、观察、停止等评分阈值；
- 评分颜色和规则说明。

评分标准支持导出规则文件和离线分享码。欢迎根据自己的式神、玩法和库存练度创建标准，也欢迎分享给其他玩家。导入别人分享的规则后，建议先预览作者、版本、适用场景和命中范围，再复制成自己的版本并启用。

### 3. 模拟强化：一键推演胚子

进入 **模拟强化**，可以把符合条件的六星未强化御魂批量推演到 `+15`，查看：

- 每个强化节点的成长轨迹；
- 最终主属性和副属性；
- 模拟后的评分和结果状态；
- 哪些胚子更值得期待。

这是纸上推演，不会修改真实御魂、金币或强化材料，也不会替你操作游戏。模拟结果只用于娱乐和理解强化可能性。

### 4. 神奇海螺：按目标面板找方案

进入 **神奇海螺**，填写你想要的目标条件，例如式神、攻击、生命、防御、速度、暴击、暴伤、效果命中或效果抵抗，再设置套装、号位和主属性要求，点击计算。

计算完成后，神奇海螺会：

- 从当前御魂库存中寻找满足目标的方案；
- 如果没有完全达标，列出最接近的方案和缺口；
- 指出可以优先强化的胚子；
- 对比强化前、一般强化收益和理论强化上限；
- 给出继续强化、补哪些属性或寻找哪些位置的建议。

理论强化上限代表“理想情况下最多能提升多少”，不代表实际强化成功率或最终结果。

### 5. 式神录：查看自己的式神

进入 **式神录**，可以查看导入数据中的式神持有和培养状态，包括：

- 式神总数、六星数量、满级数量和觉醒情况；
- 按名称搜索式神；
- 按全部、六星、满级筛选；
- 按稀有度、星级或等级排序；
- 查看单个式神的星级、等级和详细记录。

桌面版读取和藏宝阁导入都会同步写入式神录。式神录展示的是当前导入数据，不会重新扫描游戏文件。

## 使用时请注意

- 平安志不会保存游戏密码，也不会要求你把密码交给软件。
- 工具中的保留、观察、清理和强化建议只记录在本地，不会直接修改游戏。
- 导入新数据只更新当前库存；进入 **御魂分析 → 库存列表** 后，可按提示开始计算最新评分。
- 藏宝阁数据来自公开商品，部分字段（例如逐条副属性强化次数）可能无法获得，详情页会保留相应提示。
- 测试版可能存在功能不完整或界面问题。反馈问题时，请提供软件版本、Windows 版本、操作步骤和错误提示，不要上传密码或未脱敏的个人数据。

如果你要参与开发，需要：

- Node.js 22；
- Rust stable，以及 `rustfmt`、`clippy`；
- Microsoft C++ Build Tools（使用 C++ 的桌面开发）和 Windows SDK；
